# Slidev workflow

For work on a talk, start its `slides.md` deck on port 3030 and use the `slidev` MCP server as the primary interface for reading, editing, inserting, removing, reordering, and navigating slides. After an edit, navigate the live deck with MCP and verify the rendered slide. Use direct file edits for project configuration, assets, unsupported bulk transformations, or when the MCP server cannot represent the required change.
